# Escola de natação: recursos do Sistema Pacto

Flyer interativo em formato de planta baixa, com os recursos do Sistema Pacto para cada ambiente e cada pessoa de uma escola de natação.

- Passeio guiado pelos 12 ambientes
- Legenda clicável abaixo do mapa
- Cada item dos cartões tem um ícone que abre o artigo da base de conhecimento da Pacto
